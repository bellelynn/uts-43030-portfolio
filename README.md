## Three learning goals

### 🎯 Goal 1 — Ethics & Privacy in Software Engineering
**Gap closed:** From a legalistic, checklist understanding of privacy to an architectural one.

[→ See evidence](./ethics-privacy/)

Key outputs: UTS Canvas modules on professional ethics and Indigenous data sovereignty; a privacy audit of the LEXIS database schema; a refactor of the data access layer to enforce role-based access control at the repository, not just at the UI.

---

### 🔐 Goal 2 — Foundational Cybersecurity
**Gap closed:** From application-only OWASP knowledge to a working network-layer foundation.

[→ See evidence](./cybersecurity/)

Key outputs: Cisco Networking Academy Network Security course (most modules complete); input-validation and rate-limiting middleware added to the LEXIS back-end as a direct result; a documented mid-semester rescope note explaining why the goal moved from application-layer to network-layer.

---

### ⚛️ Goal 3 — Full-Stack Development with React (LEXIS)
**Gap closed:** From back-end-only to genuine full-stack delivery.

[→ See evidence](./lexis/)

Key outputs: **LEXIS**, a responsive React front-end for a Law Firm Case Management System, built against my own C# Web API. Four core workflows working: case listing, case detail, client management, time-entry logging. Source code, architecture diagram, and a demo video included.
